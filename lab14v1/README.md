## 1. Мета роботи
Навчитися використовувати спеціалізовані колекції `HashSet<T>`, `Queue<T>`, `Stack<T>` для розв’язання практичних задач, зрозуміти їхні особливості та сценарії застосування.

---

## 2. Теоретичні відомості та підзадачі (Варіант 1)

1. **`HashSet<T>` (Унікальні теги):** колекція унікальних елементів з пошуком за $O(1)$. Використана для зберігання унікальних тегів завдань та автоматичного відсіювання дублікатів.
2. **`Queue<T>` (Черга завдань):** колекція з дисципліною **FIFO** (First In, First Out). Використана для черги завдань на виконання (`Enqueue`, `Dequeue`, `Peek`).
3. **`Stack<T>` (Історія скасування Undo):** колекція з дисципліною **LIFO** (Last In, First Out). Використана для збереження історії виконаних завдань з можливістю скасування останньої дії (`Push`, `Pop`, `Peek`).

## 3. Відповіді на контрольні запитання

1. **У чому різниця між `List<T>` та `HashSet<T>`?**  
   `List<T>` зберігає дублікати, підтримує впорядкований доступ за індексом ($O(1)$), але пошук елемента займає $O(n)$. `HashSet<T>` гарантує унікальність елементів і забезпечує пошук/додавання за $O(1)$ в середньому, але не підтримує індексацію.

2. **Коли доцільно використовувати `Queue<T>` замість `List<T>`?**  
   Коли потрібна чітка обробка елементів у порядку їх надходження (FIFO) без необхідності доступу до довільного елемента за індексом.

3. **Наведіть приклад реальної задачі, де потрібен `Stack<T>`.**  
   Функціонал "Undo/Redo" в текстових/графічних редакторах, історія переходів назад у браузері, аналіз дужок у компіляторах та обхід графа/дерева в глибину (DFS).

4. **Яка складність операції `Contains()` для `HashSet<T>` і чому?**  
   Складність становить $O(1)$ в середньому, оскільки `HashSet` використовує хеш-таблицю для обчислення хеш-коду елемента та швидкого знаходження відповідного бакета.

5. **Чому `Queue<T>` називають FIFO, а `Stack<T>` - LIFO?**  
   `Queue<T>` називається **FIFO** (First In, First Out), бо перший доданий елемент вилучається першим. `Stack<T>` називається **LIFO** (Last In, First Out), бо останній доданий елемент вилучається першим.
