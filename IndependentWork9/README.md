# Самостійна робота №9
**Тема:** Вивчення Dictionary<TKey, TValue> та HashSet<T> у бібліотеках .NET  
**Студент:** Рідченко Максим  
**Група:** КН-3/1

## Реалізовані сценарії
1. Кеш метаданих файлів — `FileMetadataCache`.
2. Унікальні теги статей та операції над множинами — `TagManager`.
3. Пошуковий індекс зі знаходженням документів за одним або кількома словами — `SearchIndex`.

Аналіз трьох прикладів із відкритих проєктів, порівняльна таблиця та відповіді на контрольні запитання містяться у [REPORT.md](REPORT.md).

## Запуск
Потрібен .NET SDK 10. Команда з кореня репозиторію:

```powershell
dotnet run --project IndependentWork9/IndependentWork9.csproj
```
